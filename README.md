# Commentary Forms Mutable E2E

This repository is public so Commentary can exercise real GitHub-backed Forms
routes, but it is reserved for automated e2e writes. Tests may create temporary
branches and pull requests with names that start with `e2e/forms-`.

Do not use this repository for public demos. Stable user-facing examples live in
`commentary-dev/commentary-forms-demo`, and non-mutating smoke fixtures live in
`commentary-dev/commentary-forms-fixtures`.
